# Asset guide

Current Celestial case views, generated from CAD/Starfall_Fully_Assembled_Colored.glb:

- fully_assembled_preview.png: assembled presentation with dimensions.
- case_iso.png: angled assembled view.
- case_top.png: top view.

The assembled preview uses illustrative keycaps and knob; print only production case parts.
