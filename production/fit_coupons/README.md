# Fit samples before the full case

These are new mechanical test pieces, not parts of the finished enclosure. Print them using the same material, nozzle and settings planned for the case.

## Switch sample

`Switch_retention_14p2_14p4_14p6.STEP` has three openings. One, two and three marks identify 14.2, 14.4 and 14.6 mm lower openings respectively. All have the upper relief and 1.3 mm nominal retaining-lip stack. The case currently uses the 14.2 mm opening with an upper-edge relief.

Fit an actual supplied switch. Check that it inserts without excessive force, both latches engage, it cannot easily pull out, and a keycap can move through its full stroke. Choose the smallest opening that works reliably. If the 14.2 mm option fails, adjust the case before printing it; this sample does not automatically change the case files.

## Insert-access sample

`Insert_well_4p6_4p7_4p8.STEP` reproduces the tall posts and deep installation wells. From left to right in the source coordinates, the heat-set pockets are 4.6, 4.7 and 4.8 mm in diameter. The case uses 4.7 mm. Each post has a 5.8 mm access well and a 4.1 mm deep insert pocket.

Before heating, confirm the soldering iron's insert-setting tip fits down the access well. Install the actual M3 x 5 x 4 mm insert so its top is **6.9 mm below the post's upper support surface**. Do not leave the insert flush with the top of the post: the deep seat is necessary for the M3 x 16 screw stack. Inspect for splitting, melting through, loose inserts and thread obstruction. Let it cool and test the screw gently.

The well is deliberately tested here because the exact supplied iron tip and insert knurl dimensions are not available as measured parts. If the tip cannot reach or the insert cannot be set accurately, revise the mounting arrangement rather than forcing it.

Do not overtighten screws to compensate for a dimensional mismatch.
